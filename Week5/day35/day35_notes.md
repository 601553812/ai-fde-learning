## 错题本

### 引用编号上限未包含最后一块（已修正）

- 错误版本：`1 <= id < len(context.chunks)`。
- 正确版本：`1 <= id <= len(context.chunks)`。
- 原因：编号从1开始，最后一个有效编号等于实际发送块数；转成Python下标时才减1。
- 最小例子：实际仅有1块，引用[1]应取context.chunks[0]；原判断1<1为假，错误返回空列表。
- 同次检查发现固定跳过99；99是否越界取决于实际块数。任务单把它简写为未知编号示例，说明容易误解，助手已补具体条件；学习者已移除固定排除。
