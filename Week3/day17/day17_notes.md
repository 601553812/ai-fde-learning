### 错题本（均已修正）

1. 数据层级：错误写法 load_baseline()["raw"]；完整文件的顶层是元数据和 cases，需要先从 load_baseline()["cases"] 找到 id 为 C 的字典，再取 c["raw"]。例如 baseline={"cases":[{"id":"C","raw":"{}"}]} 时，raw 位于案例中而非顶层。当前已修正。
2. JSON 与字典：c["must_contain"] 已经是 dict，再 json.loads 会报类型错误。正确做法是直接传它；只有 raw 字符串需要 loads。例如 json.loads('{"x":1}') 得到 dict 后，无需再次 loads。字段名必须用实际存在的 must_be_empty。当前已修正。
3. 缺失判定：旧实现对每个未匹配项立刻追加 missing，空列表却不追加。应对每个关键词重新设置查找状态，在该分类搜索结束后只追加一次。例：["PDF出力","CSV出力"] 对 CSV 应通过；[] 对 CSV 应报一次缺失。当前已修正。
4. 测试结果验证（已修正）：原先只调用 evaluate(...) 不检查返回结果。现已接住返回对象并断言 structure_valid、content_passed、issues。首次验收时助手临时把 evaluate 替换为直接返回 None，旧测试仍通过；最终复查分别构造错误结构标记、内容标记和问题列表，新测试均断言失败。临时替换仅在验证进程中生效，未写入文件。
